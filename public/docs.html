توثيق API - MD-2-PDF v2.0

نظرة عامة

MD-2-PDF هي أداة سحابية لتحويل نصوص Markdown إلى ملفات PDF احترافية مع دعم كامل للغة العربية (RTL)، المعادلات الرياضية (LaTeX)، تلوين الأكواد، ومخططات PlantUML.

الرابط الأساسي: https://md-2-pdf.pages.dev

معلومات سريعة

الإصدار2.0.0
المنصةCloudflare Pages + Workers
تنسيق الطلباتJSON (Content-Type: application/json)
البروتوكولHTTPS فقط
رمز المصدرGitHub Repository

المميزات

🔤 دعم RTL

دعم كامل للغة العربية والاتجاه من اليمين لليسار

📐 LaTeX

معادلات رياضية سطرية ($x^2$) وعرضية ($$...$$)

🎨 تلوين الأكواد

Syntax Highlighting لـ JavaScript, Python, CSS, SQL وأكثر

📊 PlantUML

مخططات تسلسلية، فئات، وتدفق مباشرة في المستند

🎭 ثيمات متعددة

5 ثيمات: أزرق، أحمر، أخضر، بنفسجي، ذهبي

📄 صفحة غلاف

صفحة غلاف تلقائية مع عنوان، مؤلف، وتاريخ

⚙️ Frontmatter

YAML Frontmatter لبيانات المستند الوصفية

🤖 MCP

أدوات MCP للتكامل مع Claude, Gemini, Codex وأكثر

POST /api/convert POST

        
تحويل نص Markdown إلى ملف PDF. يعيد الملف بصيغة base64 داخل JSON.


        
المعاملات

        

          
            
المعاملالنوعمطلوبالوصف

          
          
            
markdownstring✅ نعمنص Markdown للتحويل

            
options.titlestring❌ لاعنوان المستند (يظهر بصفحة الغلاف)

            
options.authorstring❌ لااسم المؤلف

            
options.pageSizestring❌ لاA4 | Letter | Legal (افتراضي: A4)

            
options.orientationstring❌ لاportrait | landscape

            
options.fontSizenumber❌ لاحجم الخط بالبكسل (افتراضي: 10)

            
options.fontFamilystring❌ لاعائلة الخط

            
options.cssstring❌ لاCSS مخصص يُحقن في PDF

            
options.marginobject❌ لاالهوامش: {top, right, bottom, left} (مثال: "20mm")

          
        


        
مثال الطلب

        

          
          
curl -X POST https://md-2-pdf.pages.dev/api/convert \
  -H "Content-Type: application/json" \
  -d '{
    "markdown": "# مرحباً بالعالم\n\nهذا **نص** تجريبي.\n\nمعادلة: $E = mc^2$\n\n```javascript\nconsole.log(\"Hello\");\n```",
    "options": {
      "title": "مستندي",
      "pageSize": "A4"
    }
  }'

        


        
الاستجابة (نجاح)

        

          
          
{
  "success": true,
  "pdf": "JVBERi0xLjQK...",
  "metadata": {
    "title": "مستندي",
    "createdAt": "2026-05-20T00:00:00.000Z"
  }
}

        


        
الاستجابة (خطأ - تجاوز الحد)

        

          
          
{
  "success": false,
  "error": "تم تجاوز حد التحويل اليومي...",
  "fallback": true,
  "html": "<html>...",
  "metadata": { ... }
}

        


        

          ⚠️ ملاحظة: حقل pdf يحتوي على ملف PDF كامل بصيغة base64. استخدم atob() في JavaScript أو base64 -d في الطرفية لاستخراج الملف.

تحليل Markdown واستخراج البيانات الوصفية + معاينة HTML. لا ينشئ PDF.


        
المعاملات

        

          
            
المعاملالنوعمطلوبالوصف

          
          
            
markdownstring✅ نعمنص Markdown للتحليل

            
optionsobject❌ لاخيارات التحويل (نفس convert)

          
        


        
مثال الطلب

        

          
          
curl -X POST https://md-2-pdf.pages.dev/api/parse \
  -H "Content-Type: application/json" \
  -d '{
    "markdown": "---\ntitle: مستندي\nauthor: أحمد\n---\n\n# مرحباً\n\n**نص عريض** مع `كود`"
  }'

  "html": "<!DOCTYPE html><html lang=\"ar\" dir=\"rtl\">...",
  "metadata": {

    "author": "أحمد",
    "createdAt": "2026-05-20T00:00:00.000Z"
  }
}

🤖 خادم MCP (عن بُعد على Cloudflare)

        

          نقطة النهاية الوحيدة:
          https://md-2-pdf.pages.dev/mcp
          

          خادم MCP يعمل مباشرةً على Cloudflare Pages عبر Streamable HTTP — لا حاجة لتثبيت Node.js أو استنساخ المشروع أو بنائه محلياً. أي عميل MCP متوافق يتصل بهذا الرابط فقط.
        


        
الخادم يوفّر 5 أدوات للذكاء الاصطناعي لتحويل Markdown والتحكم بسجل التحويلات:


        

          

            convert-markdown-to-pdf
            تحويل مباشر
          

          
تحويل نص Markdown إلى ملف PDF (Base64). يدعم: frontmatter، تلوين الكود، رياضيات KaTeX، رسوم PlantUML، تخطيطات عربية/RTL.

          

            
المعاملالنوعالوصف

            
              
markdownstringنص Markdown (مطلوب)

              
pageSizeenumA4 | Letter | Legal

              
orientationenumportrait | landscape

              
directionenumrtl | ltr | hybrid

              
fontSizenumberحجم الخط (8–24)

              
cssstringCSS إضافي

              
marginobject{ top, right, bottom, left }

              
filenamestringاسم الملف المقترح

              
saveToHistorybooleanحفظ في السجل (يتطلب auth)

            
          

        


        

          

            parse-markdown
            تحليل
          

          
تحويل Markdown إلى HTML منسّق + استخراج الـ frontmatter. لا يستخدم الشبكة (سريع جداً).

          

            
المعاملالنوعالوصف

            
              
markdownstringنص Markdown (مطلوب)

              
+ نفس خيارات التحويل أعلاه (pageSize, direction, …)

            
          

        


        

          

            list-documents
            سجل
          

          
عرض المستندات المحوّلة سابقاً للمستخدم أو الجلسة الضيف. يتطلب auth.

          

            
المعاملالنوعالوصف

            
              
limitnumberعدد النتائج (1–200)

              
offsetnumberترقيم الصفحات

              
searchstringبحث في العناوين

            
          

        


        

          

            get-document
            سجل
          

          
جلب مستند واحد بالكامل (Markdown + metadata) عبر معرّفه الرقمي.

          

            
المعاملالنوعالوصف

            
              
idnumberمعرّف المستند (مطلوب)

            
          

        


        

          

            create-guest-session
            auth
          

          
إنشاء جلسة ضيف UUID لحفظ التحويلات بدون تسجيل حساب. استخدم الناتج في _meta.auth.guestSessionId.

🧪 اختبار MCP

        
كل طلب MCP هو عبارة عن JSON-RPC 2.0 عبر POST. جرّب مباشرةً بـ curl:


        
1) سرد الأدوات المتاحة

        

          
          
curl -X POST https://md-2-pdf.pages.dev/mcp \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -H "MCP-Protocol-Version: 2025-06-18" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18","capabilities":{},"clientInfo":{"name":"curl","version":"1.0"}}}'

        


        
2) تحويل Markdown إلى PDF

        

          
          
curl -X POST https://md-2-pdf.pages.dev/mcp \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -H "MCP-Protocol-Version: 2025-06-18" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"convert-markdown-to-pdf","arguments":{"markdown":"# مرحباً\\nهذا **اختبار** من MCP","direction":"rtl"}}}'

        


        
3) فحص نص FYI

        

          
          
curl https://md-2-pdf.pages.dev/mcp

        

        
سيعيد JSON تعريفي يصف الخدمة (مفيد للتأكد أن الخادم حيّ).
